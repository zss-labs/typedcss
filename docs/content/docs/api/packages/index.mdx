---
title: 'Packages'
description: 'Packages built on TypedCSS, shipped as source or as a dist.'
---

| Package | Ships as | |
| :-- | :-- | :-- |
| [`@typedcss/wind`](/docs/api/packages/wind) | Source | Tailwind CSS theme values as static tokens |

A package shipped as source is compiled by the app's build, so a style the app passes
in is compiled with the app. A dist works in any app.

- [Build your own](/docs/creating-packages)
