> **Installation comes first**
>
> Always load the installation guide before asking an agent to write TypedCSS. The compiler and bundler integration are part of the programming model, not optional setup around it.

## Start here

Copy this into your agent's prompt:

```text title="Prompt for your coding agent"
Read these TypedCSS documents in order before making changes:

1. Installation — /docs/installation
2. Rules for AI agents — /docs/ai.md
3. Introduction and core usage — /docs

Follow AI.md as authoritative. Inspect the existing project's bundler and framework,
then read the matching integration guide before changing configuration.
```

[AI.md](/docs/ai.md) is plain Markdown, generated from these docs.

## Working examples

The [`examples/` directory](https://github.com/zss-labs/typedcss/tree/main/examples) contains compiling projects for Next.js, Vite, Rollup, Rspack, webpack, esbuild, Bun, Farm, and Rolldown, plus React Router, Waku, Vue, Svelte, Solid, Qwik, Preact, Astro, and Storybook. Point an agent to the matching example when it needs a complete configuration rather than an isolated snippet.
