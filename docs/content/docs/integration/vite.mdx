[`examples/example-vite-react`](https://github.com/zss-labs/plumeria/tree/main/examples/example-vite-react) shows how to use [`@typedcss/unplugin`](https://www.npmjs.com/package/@plumeria/unplugin) in Vite.  
The plugin compiles TypedCSS styles into CSS, with HMR in development.

`npx @typedcss/init` detects Vite and writes this setup for you; see [@typedcss/init](/docs/api/migrate/init). The rest of this page is the same setup by hand.

## Installation
```sh title="Terminal"
pnpm i -D @typedcss/unplugin
```

## Usage

```ts title="vite.config.ts"
import { defineConfig } from 'vite';
import typedcss from '@typedcss/unplugin';

export default defineConfig({
  plugins: [typedcss.vite()],
});
```

`typedcss.vite()` accepts an options object:

```ts title="vite.config.ts"
export default defineConfig({
  plugins: [
    typedcss.vite({
      include: ['./src/**/*.{ts,tsx}'],
      exclude: ['**/node_modules/**'],
      styleProp: 'classStyle',
    }),
  ],
});
```

- `include` — Globs or regular expressions for the files to compile.
- `exclude` — Globs or regular expressions for the files to leave out.
- `styleProp` — The JSX prop that carries styles. The default is `'sx'`.

These are the options a project usually sets. `devEmitToDisk` writes the stylesheet to disk in development, and `withoutLogicalProperties` / `withoutPhysicalProperties` reject one spelling of a property that carries both names, so the pair cannot be written; see [@typedcss/unplugin](/docs/api/plugins/unplugin) for every option and its type.

## typedcss.d.ts

`@typedcss/css` ships no prop declaration of its own, so name the styling prop your project compiles with.

For the default name (`sx`), reference the declaration that ships with the package, in `src/` when the project has one or at the application root otherwise:

```ts title="typedcss.d.ts"
/// <reference types="@typedcss/css/sx" />
```

If you set a custom `styleProp` (such as `'classStyle'`), declare that name instead, and keep it the same as the one in `vite.config.ts`; see [Declaring the styling prop](/docs/api/types/Style#declaring-the-styling-prop).
